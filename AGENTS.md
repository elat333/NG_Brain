# Custom Instructions for AI Studio

## Workflow & Code Modification
* **Explicit Confirmation Required**: SIEMPRE, sin excepción, debes explicar la solución o el plan al usuario y pedir confirmación explícita ANTES de modificar, borrar o crear archivos en el código fuente de la aplicación. No hagas cambios hasta que el usuario te dé luz verde.
* **Strict Git Push Confirmation**: ANTES de ejecutar `git push` hacia GitHub o producción, SIEMPRE debes pedir confirmación expresa solicitando al usuario que escriba textualmente: **`"Hacer Git Push"`**. Queda terminantemente prohibido hacer push sin que el usuario haya escrito exactamente esa frase de confirmación de seguridad.
